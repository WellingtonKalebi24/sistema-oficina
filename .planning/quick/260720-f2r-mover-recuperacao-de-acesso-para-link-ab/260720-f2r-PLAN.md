# Quick Task 260720-f2r: Mover recuperacao de acesso para link abaixo do login

## Goal

Adjust the Phase 2 login UI so password/account recovery is not rendered as a side panel beside the login form.

## Scope

- Keep login as the first visible access surface.
- Add a compact `Recuperar acesso` action below the login submit button.
- Render the recovery form below the login only after that action is clicked.
- Preserve existing reset endpoints and messages.
- Update web UI tests to assert the recovery panel is initially absent.

- `npm run typecheck -w apps/web`
- `npm run lint -w apps/web`
