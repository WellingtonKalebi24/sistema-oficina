<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to catalog API | Authenticated but untrusted JSON crosses into backend validation. |
| Catalog API to database | Tenant-scoped writes create durable operational data. |
| Permission seed to protected routes | Permission key drift can weaken authorization. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Elevation of privilege | stockCatalog routes | high | mitigate | Use requirePermission for every catalog route and seed keys through centralized PERMISSIONS. |
| T-04-02 | Information disclosure | catalogService tenant lookups | high | mitigate | Filter every list/read/write by req.auth.tenantId and return 404 for foreign IDs. |
| T-04-03 | Repudiation | catalog mutations | medium | mitigate | Write sanitized audit rows with tenantId, userId, action, entity, recordId and compact metadata. |
| T-04-SC | Tampering | npm installs | high | mitigate | No package install or upgrade is planned; keep existing pinned stack. |
</threat_model>
