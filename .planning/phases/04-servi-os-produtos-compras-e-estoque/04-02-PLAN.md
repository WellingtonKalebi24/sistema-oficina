## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to movement API | Quantity, source and reason input is untrusted. |
| API transaction to PostgreSQL | Stock invariants must be protected across concurrent writers. |
| Audit payload to audit_logs | Operational metadata must be useful without storing sensitive raw input. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-04 | Tampering | ProductStock writes | critical | mitigate | Use transaction plus row lock or guarded conditional update before stock mutation. |
| T-04-05 | Information disclosure | relation IDs | high | mitigate | Validate product and supplier ownership by tenant before every write. |
| T-04-06 | Repudiation | purchase/exit/adjustment actions | high | mitigate | Write audit rows in the same transaction as the stock movement. |
| T-04-SC | Tampering | npm installs | high | mitigate | No package install or upgrade is planned; keep existing pinned stack. |
</threat_model>
