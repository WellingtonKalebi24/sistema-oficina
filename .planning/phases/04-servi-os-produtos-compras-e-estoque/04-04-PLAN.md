<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser state to API | UI state is convenience only and cannot authorize stock actions. |
| Operator-visible tables | Tenant data returned by backend must not be mixed across sessions. |
| Critical UI actions | Destructive and stock-changing actions must call backend endpoints that audit and transact. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-10 | Elevation of privilege | Estoque buttons/forms | medium | mitigate | Hide disabled actions for usability but rely on backend 403 and display blocked state. |
| T-04-11 | Information disclosure | stock tables | high | mitigate | Load only authenticated API data and clear stock state on invalid session/logout. |
| T-04-12 | Tampering | critical stock forms | medium | mitigate | Client submits to transactional backend endpoints and refreshes server data after success. |
| T-04-SC | Tampering | npm installs | high | mitigate | No package install or upgrade is planned; keep existing pinned stack. |
</threat_model>
