## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator browser to web app | Operator input drives searches and mutations through the authenticated shell. |
| web app to protected API | Browser sends bearer tokens and customer/vehicle payloads to Express. |
| UI permission visibility to backend authorization | Menus can hide actions, but only backend 401/403 proves access control. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03-01 | Elevation of Privilege | customer/vehicle UI menus | medium | mitigate | Use permission-aware menus only for usability and test API 403 blocked states per D-09. |
| T-03-03-02 | Information Disclosure | customer/vehicle client state | medium | mitigate | Do not persist customer/vehicle records in localStorage; use in-memory React state only. |
| T-03-03-03 | Information Disclosure | UI errors | medium | mitigate | Surface concise Portuguese errors without stack traces, tokens, raw documents or secret material. |
| T-03-03-04 | Tampering | soft delete/destructive actions | medium | mitigate | Require explicit destructive confirmation and verify backend delete response before removing active rows. |
| T-03-03-05 | Spoofing | prohibited communication affordances | low | mitigate | UI tests assert absence of WhatsApp, SMS, email sending, notification, delivery/read and marketing language. |
| T-03-03-SC | Tampering | npm installs | high | mitigate | No package installation in this plan; research recommends existing web/API stack only. |
