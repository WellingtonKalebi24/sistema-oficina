## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated API user to operational records | Authenticated users submit customer/vehicle identifiers and PII that must be validated and tenant-scoped. |
| tenant A data to tenant B data | Shared PostgreSQL stores operational records for multiple workshops. |
| API duplicate checks to database constraints | Concurrent requests can bypass service-only duplicate checks unless PostgreSQL enforces active uniqueness. |
