<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to API | User-entered foundation labels cross from the UI to Express endpoints. |
| Operator to documentation | Developers follow docs that can affect local secrets and database state. |
| Visual alerts to product behavior | UI state patterns can accidentally imply communication features. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03-T1 | Tampering | Web foundation form | medium | mitigate | Keep server-side validation in Plan 02 route and test UI error handling for rejected responses. |
| T-01-03-I1 | Information Disclosure | Local setup docs | medium | mitigate | Document sample `.env` values only and direct real secrets to untracked `.env`. |
| T-01-03-I2 | Information Disclosure | UI state examples | low | mitigate | Use neutral foundation data only; do not display business, tenant, customer or financial data in Phase 1. |
| T-01-03-S1 | Spoofing | Notification-like visual patterns | medium | mitigate | Visual contract states calculated visual alerts only and forbids centers, counters and outbound communication behavior. |
</threat_model>
