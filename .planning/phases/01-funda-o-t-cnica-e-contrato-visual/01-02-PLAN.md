<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser or local client to API | Untrusted HTTP input reaches Express route handlers. |
| API to PostgreSQL | Application data crosses into persistent storage through Prisma. |
| Docker host to containers | Local environment variables and ports are exposed to containers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-02-I1 | Information Disclosure | Express error middleware | medium | mitigate | Return generic error JSON, keep stack traces out of responses, and test forced error behavior. |
| T-01-02-I2 | Information Disclosure | API logging | medium | mitigate | Use structured logging without request bodies or env values; verify log shape in API tests. |
| T-01-02-D1 | Denial of Service | API startup with DB unavailable | medium | mitigate | Compose DB healthcheck plus API `depends_on: condition: service_healthy`; health route requires DB query. |
| T-01-02-T1 | Tampering | Seed data | low | mitigate | Seed uses deterministic upsert of neutral data and is safe to rerun locally. |
</threat_model>
