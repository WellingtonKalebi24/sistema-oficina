## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser to web app | Operator input controls session state and admin UI actions. |
| web app to API | Browser sends bearer tokens and admin mutations to Express. |
| local runtime to Docker stack | Compose smoke validates db/api/web integration. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-06-01 | Spoofing | web session storage | medium | mitigate | Store only required token material, clear on logout, and rely on API `requireAuth` for authority. |
| T-02-06-02 | Elevation of Privilege | admin menu visibility | medium | mitigate | Menu visibility is UX only; API 403 states are tested and surfaced per D-16. |
| T-02-06-03 | Information Disclosure | UI error states | medium | mitigate | Portuguese errors avoid stack traces, token values, SMTP secrets and reset codes. |
| T-02-06-04 | Tampering | final migration/runtime | high | mitigate | Final gate runs `npm run db:migrate`, `npm run verify` and Docker config/smoke checks. |
