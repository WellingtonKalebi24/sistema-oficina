## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated browser to admin API | Authenticated but untrusted users request tenant settings, user and permission changes. |
| tenant A data to tenant B data | Shared database stores records for multiple workshops. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-05-01 | Elevation of Privilege | user and role assignment | high | mitigate | Enforce `users.createAdmin` before admin-level grants per D-03 and test denial. |
| T-02-05-02 | Information Disclosure | tenant-scoped admin reads | high | mitigate | Every query filters by `req.auth.tenantId`; two-tenant tests cover reads and writes. |
| T-02-05-03 | Tampering | permission overrides | high | mitigate | Override writes require permission, validate tenant relations and audit changes. |
| T-02-05-04 | Repudiation | admin changes | medium | mitigate | Audit tenant settings, user lifecycle, role and override events with sanitized payloads. |
| T-02-05-SC | Tampering | npm installs | high | mitigate | No package installation in this plan; package gate completed in Plan 02-01. |
</threat_model>
