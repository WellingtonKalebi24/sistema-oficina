## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser to public auth API | Untrusted bootstrap credentials, login credentials and token material enter Express routes. |
| API to PostgreSQL | Password hashes and hashed refresh-token sessions are persisted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-03-01 | Spoofing | `POST /auth/login` | high | mitigate | Argon2id verification, generic failures, rate limiting config and sanitized responses. |
| T-02-03-02 | Tampering | session refresh rotation | high | mitigate | Store hashed opaque refresh tokens and rotate in a transaction per D-08, D-09 and D-10. |
| T-02-03-03 | Elevation of Privilege | bootstrap route | high | mitigate | Transactionally reject bootstrap after the first tenant/admin exists per D-01. |
| T-02-03-SC | Tampering | npm installs | high | mitigate | Depends on completed Plan 02-01 package gate for `argon2`, `jose`, `zod` and `express-rate-limit`. |
</threat_model>
