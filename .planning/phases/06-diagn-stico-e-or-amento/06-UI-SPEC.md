## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, required marker offset, compact inline separation |
| sm | 8px | Button row gaps, table action gaps, badge icon gaps |
| md | 16px | Default panel padding, form groups, workspace gutters |
| lg | 24px | Section padding, major panel separation, quote summary spacing |
| xl | 32px | Page gutters on desktop, large grouped quote sections |
| 2xl | 48px | Major vertical breaks only when separating quote list from detail workspace |
| 3xl | 64px | Page-level spacing; avoid inside dense Phase 6 panels |

Exceptions: `12px` is allowed because it already exists as `--space-3` for compact table cells, form gaps and field padding. Interactive controls must keep current minimums: buttons 40px, inputs 42px, mobile navigation/action targets 44px or larger.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f4f7f6` | Page background and broad workspace surface |
| Secondary (30%) | `#ffffff`, `#eef3f1` | Panels, tables, quote item groups, muted strips, read-only published snapshots |
| Accent (10%) | `#176b5b` | Primary command buttons, active `Orcamentos` navigation item, active tabs, selected quote row, published-ready success emphasis |
| Destructive | `#b4343a` | Cancel quote, discard draft, delete item and failed/error states only |

Accent reserved for: `Criar orcamento`, `Salvar rascunho`, `Publicar versao`, active segmented tabs, selected quote row, copied-link success state and focus-compatible active indicators. Do not use accent on every link, table value or decorative border.

Warning support: use existing warning treatment `#c58b2f` / `#fff7e8` only for discount-above-limit warnings, expiring validity, stock availability warnings and "manual delivery only" guard copy. Warning is not a destructive color and must not block the D-08 discount workflow.

## Phase 6 Layout Contract

Primary view: add an authenticated `Orcamentos` operational view in the existing admin shell. Keep the screen table-first and dense like Agenda/Estoque, not a landing page.

Desktop layout:

| Region | Contract |
|--------|----------|
| Top controls | Compact filters above the quote table: search, status, source (`Check-in`/`Direto`), validity range and refresh action. |
| Main list | Table of quotes with customer, vehicle, source, status, current version, validity, total and actions. Minimum table width: 900px with horizontal overflow on narrow screens. |
| Detail workspace | Two-column grid after a quote is selected: left column for diagnosis/source/customer data, right column for commercial items and totals. |
| Summary rail | Sticky-within-panel total summary on desktop only if it does not overlap content; otherwise keep it at the bottom of the commercial panel. |

Mobile layout:

| Region | Contract |
|--------|----------|
| Controls | Filters stack in one column; no required control may hide behind horizontal scroll. |
| List | Quote table may scroll horizontally; row actions wrap with 44px minimum touch targets. |
| Detail | Diagnosis, items, totals, version history and actions stack in that order. |

Do not nest cards inside cards. Use `.panel` for major regions and use compact item rows/tables for repeated services/products.

## Phase 6 Interaction Contract

Quote creation entry points:

| Entry Point | UI Contract |
|-------------|-------------|
| From check-in | Show check-in selector with customer, vehicle, reception date and status. Diagnosis fields `problema`, `causa`, `recomendacao` are required before `Publicar versao` becomes available. |
| Direct customer/vehicle | Show customer and vehicle selectors. Diagnosis fields remain optional; quote can proceed as a commercial quote. |

Diagnosis panel:

| Field | Contract |
|-------|----------|
| Problema | Multi-line textarea, visible label, required only for check-in-origin publish. |
| Causa | Multi-line textarea, visible label, required only for check-in-origin publish. |
| Recomendacao | Multi-line textarea, visible label, required only for check-in-origin publish. |
| Internal observations | If implemented, visibly marked `Interno`; never shown in PDF/link preview. |

Items and totals:

| Interaction | Contract |
|-------------|----------|
| Add service | Search/select from service catalog, snapshot description and price into the draft, allow quantity and item discount/surcharge. |
| Add product/part | Search/select from products, show availability/reservation context, snapshot public item data, allow quantity and item discount/surcharge. |
| Grouping | Single quote list in data model, but UI must visually group `Servicos` and `Produtos/pecas` in both editor and PDF preview. |
| Totals | Show subtotal, item discounts, item surcharges, quote-level discount, quote-level surcharge and final total in BRL. Recalculate immediately on edit. |
| Discount limit | Above-limit discount shows warning only; saving and publishing remain available unless backend rejects for another reason. |
| Validity | Required before publish. Use `pt-BR` date display and native/date input behavior consistent with existing forms. |
| Estimated delivery | Optional; never block save/publish solely because it is empty. |

Versioning and publishing:

| State | Contract |
|-------|----------|
| Rascunho | Editable fields and item controls visible. CTA order: `Salvar rascunho`, `Publicar versao`. |
| Publicado | Commercial fields become read-only. Show lock notice and expose `Copiar link`, `Imprimir/Gerar PDF`, `Criar nova versao` and optional `Marcar como enviado`. |
| Enviado | Manual status badge only. Must not trigger WhatsApp, email, SMS, push, notification record, delivery tracking or read tracking. |
| Expirado | Calculated/operational status with warning styling; allow new version if backend permits. |
| Cancelado | Read-only commercial snapshot with destructive status styling and audit-friendly history. |

PDF/link actions:

| Action | Contract |
|--------|----------|
| Copiar link | Enabled only for published versions. Copies secure approval link to clipboard and shows local success copy: `Link copiado para entrega manual.` |
| Imprimir/Gerar PDF | Enabled only for published versions. Opens/loads PDF generated from the immutable version snapshot. |
| Preview | Customer-facing preview must exclude internal costs, margin, supplier data, internal notes and audit/admin data. |

States:

| State | Contract |
|-------|----------|
| Loading | Use skeleton table rows or compact status text: `Sincronizando orcamentos com a API.` |
| Empty | Use copywriting contract above with a visible `Criar orcamento` action when permitted. |
| 403 | Show `Acesso bloqueado pela permissao do servidor.` in the existing blocked panel style. |
| Validation | Inline, concise, action-oriented. Backend validation remains authoritative. |
| Success | Confirm local persisted action only; never claim customer delivery. |
